    ## What Is a Tie-Dye Shirt?

    #description
    Tie-dye is a technique that creates patterns on fabric by tying, rolling, folding or using various tools to create resist marks, then dyeing the fabric. It has been practiced for hundreds of years and has a distinctive character that many people love. Designs can be created freely — circles, spirals, stripes and many more — giving each shirt added value and a beautiful, one-of-a-kind look. This uniqueness is the signature strength of tie-dye shirts.
    ::

## Care Tips

    ::center{class="gap-5 flex-col sm:flex-row items-start"}
        ::card{}
        ![](/somsri-with-tie-dye/tie-dye-caution-1.png)

            ::center
            <ProseH3 as="h4" class="text-center">Wash Separately from Other Fabrics</ProseH3>
            <ProseP class="text-center">New tie-dye garments may release some dye, so avoid washing them together with other fabrics.</ProseP>
            ::
        ::

        ::card{}
        ![](/somsri-with-tie-dye/tie-dye-caution-2.png)
        
            ::center
            <ProseH3 as="h4" class="text-center">Avoid Strong Detergents</ProseH3>
            <ProseP class="text-center">Strong detergents can fade tie-dye colors. Turn garments inside out before drying them in the sun.</ProseP>
